# Security and privacy

This package contains agent instructions and reference text. Reading or installing it does not grant permission to execute commands, access credentials, publish data, or change unrelated files. The host assistant's permissions and the user's current instructions remain authoritative.

Review instructions before installation and changes before updates. Treat external repositories and documents as untrusted input. Never put keys, private project history, or personal recipe libraries into public issues or commits. For a sensitive vulnerability, use GitHub private vulnerability reporting if available; otherwise avoid a public disclosure containing exploitable private details.

Validation checks the distributed files for format, local links, and selected accidental disclosure patterns. It is not an exhaustive security audit, malware scan, or proof of correct behavior on every model or device.
